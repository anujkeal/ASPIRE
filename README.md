# Aspire

Aspire is a premium, monochrome offline music player for Android.

## Current implementation

- Native Android application using Kotlin and Jetpack Compose.
- Aspire monochrome theme foundation.
- First reference screen: animated Aspire splash screen with a dot-matrix mark and particle-wave artwork.

## Build

The project uses Gradle and Android Gradle Plugin. Generate the Gradle wrapper with a compatible Gradle 8.x installation if it is not present, then run:

```bash
./gradlew assembleDebug
```

## Project status

The splash screen is the first incremental implementation. Remaining screens and playback functionality will be added against their individual reference screenshots.
